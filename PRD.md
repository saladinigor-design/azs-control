# PRD: «Склад ГСМ» — система учёта прихода и расхода нефтепродуктов

## 1. Назначение продукта

Веб-приложение для учёта движения нефтепродуктов (НП) на складе ГСМ: фиксация приходов от поставщиков, расходов по объектам-получателям, контроль текущих остатков по каждому виду топлива, отчётность за сутки и за произвольный период, а также визуальный контроль критически низкого остатка («мёртвый остаток»).

## 2. Виды нефтепродуктов

Система работает с тремя видами топлива:

- АИ-92
- АИ-95
- ДТ (дизельное топливо)

Остаток, приход и расход учитываются раздельно по каждому виду.

## 3. Функциональные требования

### 3.1 Учёт прихода НП
Форма добавления прихода содержит поля:
- Дата прихода
- Вид НП (АИ-92 / АИ-95 / ДТ)
- Объём, л
- Поставщик / документ основания

Каждая запись сохраняется в журнал операций и увеличивает текущий остаток соответствующего вида топлива.

### 3.2 Учёт расхода НП
Форма добавления расхода содержит поля:
- Дата расхода
- Вид НП (АИ-92 / АИ-95 / ДТ)
- Объём, л
- Объект назначения (куда отправлено топливо)

Каждая запись сохраняется в журнал операций и уменьшает текущий остаток соответствующего вида топлива.

### 3.3 Отображение текущих остатков
На главном экране постоянно отображаются три карточки-«резервуара» (по одной на вид НП), каждая показывает:
- Текущий объём НП на складе, л
- Визуальный уровень заполнения относительно вместимости
- Редактируемую вместимость резервуара
- Редактируемый порог «мёртвого остатка» (см. п. 3.6)

Остаток рассчитывается автоматически как сумма приходов минус сумма расходов по каждому виду НП.

### 3.4 Отчёт за сутки
Отдельный блок позволяет выбрать конкретную дату и увидеть:
- Список всех приходов за эти сутки (вид НП, объём, поставщик) с итоговой суммой
- Список всех расходов за эти сутки (вид НП, объём, объект) с итоговой суммой

### 3.5 Журнал операций: сортировка и поиск
Общая таблица всех операций (приход + расход) поддерживает:
- Сортировку по дате (клик по заголовку столбца, по возрастанию/убыванию)
- Сортировку по объёму (клик по заголовку столбца, по возрастанию/убыванию)
- Фильтр по типу операции (приход / расход / все)
- Фильтр по виду НП
- Фильтр по диапазону дат («с» / «по») — для поиска выбытия или прихода НП за определённый период
- Текстовый поиск по контрагенту (поставщику или объекту назначения)
- Кнопку сброса всех фильтров
- Удаление отдельной операции из журнала

### 3.6 Контроль «мёртвого остатка»
Для каждого вида НП задаётся собственный порог мёртвого остатка (редактируемое значение, по умолчанию: 500 л для АИ-92 и АИ-95, 800 л для ДТ).

Когда текущий остаток вида НП опускается до порога или ниже него, срабатывает визуальная индикация:
- Карточка резервуара окрашивается в красный цвет и пульсирует (мигающая обводка)
- Значение остатка и название топлива выделяются красным
- На карточке появляется бейдж «Достигнут мёртвый остаток»
- Над блоком резервуаров появляется общий баннер-предупреждение с перечислением всех НП, находящихся в критической зоне

Индикация автоматически снимается, как только остаток превышает установленный порог.

### 3.7 Формирование Excel-отчёта за период
Пользователь задаёт период (дата «с» — дата «по», по умолчанию — текущий месяц) и по кнопке скачивает файл `.xlsx` со следующими листами:

| Лист | Содержимое |
|---|---|
| Приход — операции | Построчный список всех приходов за период: дата, вид НП, объём, поставщик/документ |
| Приход — по поставщикам | Сводная таблица: суммарный объём по каждому поставщику в разрезе АИ-92 / АИ-95 / ДТ, с итоговой строкой |
| Расход — операции | Построчный список всех расходов за период: дата, вид НП, объём, объект назначения |
| Расход — по объектам | Сводная таблица: суммарный объём, отправленный на каждый объект, в разрезе АИ-92 / АИ-95 / ДТ, с итоговой строкой |
| Итоги | По каждому виду НП: остаток на начало периода, приход за период, расход за период, остаток на конец периода |

Имя файла формируется автоматически по датам периода.

## 4. Модель данных

### 4.1 Операция (запись журнала)
| Поле | Тип | Описание |
|---|---|---|
| id | строка | уникальный идентификатор записи |
| type | in / out | приход или расход |
| fuel | ai92 / ai95 / dt | вид НП |
| date | дата | дата операции |
| volume | число | объём, л |
| party | строка | поставщик (для прихода) или объект назначения (для расхода) |

### 4.2 Настройки по виду НП
| Поле | Описание |
|---|---|
| capacity | вместимость резервуара, л (для визуализации уровня заполнения) |
| deadLevel | порог мёртвого остатка, л |

## 5. Нефункциональные требования

- **Хранение данных**: все операции и настройки (вместимость, мёртвый остаток) сохраняются персистентно и восстанавливаются при повторном открытии приложения — без необходимости повторного ввода.
- **Локализация**: интерфейс полностью на русском языке, формат дат — ДД.ММ.ГГГГ.
- **Адаптивность**: интерфейс корректно отображается как на десктопе, так и на мобильных экранах.
- **Отсутствие сервера**: приложение работает как самостоятельный файл, не требует внешней базы данных или бэкенда.

## 6. Реализация (техническая справка)

- Формат: одностраничное веб-приложение (HTML/CSS/JavaScript), поставляется единым файлом `sklad-gsm.html`.
- Хранение данных — персистентное key-value хранилище приложения (данные приходов/расходов, вместимости резервуаров, пороги мёртвого остатка).
- Генерация Excel-отчётов — библиотека SheetJS (формирование `.xlsx` на стороне клиента, скачивание файла по кнопке).
- Стиль оформления — тёмная промышленная тема: цветовая дифференциация по видам топлива (АИ-92 — янтарный, АИ-95 — оранжевый, ДТ — бирюзовый), приход/расход — зелёный/красный.

## 7. История изменений требований (по переписке)

1. Базовая версия: учёт прихода/расхода по трём видам НП, окно текущих остатков, окно прихода/расхода за сутки, сортировка и поиск по датам и объёмам.
2. Добавлена выгрузка Excel-отчёта за выбранный период с группировкой прихода по поставщикам и расхода по объектам назначения.
3. Добавлен контроль мёртвого остатка по каждому виду топлива с визуальной индикацией (красная подсветка и мигание) при достижении порога.

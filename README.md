# Контроль выполнения задач — сеть АЗС

Веб-инструмент для операционного контроля за выполнением задач сотрудниками сети автозаправочных станций (АЗС). Даёт руководителю сети единую картину: какие задачи поставлены, кто за них отвечает, соблюдаются ли сроки, и позволяет связаться с ответственным сотрудником через WhatsApp.

Полное описание требований — в [PRD_2.md](PRD_2.md).

## Запуск

Инструмент — самодостаточный HTML-файл без серверной части и зависимостей.

Достаточно открыть [`azs_control.html`](azs_control.html) в браузере (двойной клик по файлу или `File → Open`).

## Возможности

- Сводный дашборд: % выполнения по каждому типу чек-листа, число просроченных задач.
- Структура контроля: начальник торгового отдела → менеджеры → товароведы → станции, с редактируемыми телефонами.
- 4 типа чек-листов: состояние АЗС (смена), товароведческий, менеджера, начальника торгового отдела.
- Жизненный цикл задачи: Постановка → Ответственный → Срок → Контроль → Подтверждение → Проверка → Закрытие, с автоматическим статусом «Просрочено».
- График/таблица выполнения по станциям.
- Фильтры по контролёру, станции, смене и статусу задачи.
- Формы: поставить задачу сотруднику, добавить АЗС, добавить смену, добавить задачу в шаблон чек-листа.
- Кнопка «💬 WhatsApp» на каждой задаче — открывает чат с ответственным и предзаполненным текстом.
- Светлая/тёмная тема, адаптивная вёрстка.

## Ограничения текущей версии

- Все данные хранятся в памяти браузера и сбрасываются при перезагрузке страницы — постоянного хранилища и синхронизации между пользователями нет.
- Авторизации и разграничения доступа нет.
- Номера телефонов в исходном состоянии — плейсхолдеры, не привязанные к реальным людям.

Подробнее — раздел «Ограничения текущей реализации» в [PRD_2.md](PRD_2.md).
